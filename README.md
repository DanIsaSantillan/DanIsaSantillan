## Proyectos


### 🧶 Amigurumi Lovers' Shop
Tienda OnePage de amigurumis por encargo. Calcula automáticamente el precio, el anticipo del 50% y la fecha estimada de entrega, y genera el pedido como un mensaje listo para enviar por WhatsApp. Incluye comentarios de clientes con Firebase y un modo administrador protegido por PIN.


**Tecnologías:** HTML, CSS, Bootstrap, JavaScript, JSON, Firebase
🔗 [Ver en vivo](https://danisasantillan.github.io/amigurumis-lovers-shop/) · 📂 [Código](https://github.com/DanIsaSantillan/amigurumis-lovers-shop)

### 🎨 Galería de MarseSan
Galería personal para guardar y organizar mis dibujos por categorías, con búsqueda, comentarios de visitantes y un panel de administrador que publica las imágenes directamente en GitHub usando su API con autenticación por token.


**Tecnologías:** HTML, CSS, Bootstrap, JavaScript, GitHub API, Firebase

Página para escribir, guardar y leer mis historias organizadas por universo, con editor de texto enriquecido (Quill), texto a voz y un diccionario personalizado para el corrector. Las historias se guardan en Firebase.


**Tecnologías:** HTML, CSS, Bootstrap, JavaScript, Firebase, Quill
